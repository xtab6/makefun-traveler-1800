One sentence for a traveler from 1800: a single sentence explaining the modern internet to someone who has just stepped out of the year 1800 — written by a small deterministic program for the bounty of the same name on make.fun. The program writes the sentence to /output/entry.txt.

## Run it

```sh
python3 main.py
```
